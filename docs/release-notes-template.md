Windows users: choose the `windows-x64-setup.exe` installer for in-app updates. The executable without `-setup` is portable and requires manual replacement.

Linux users: choose the AppImage for portable in-app updates, or DEB/RPM for native installation. AppImage users need separately configured non-root dumpcap capture. Native package updates may request system authorization.

Updates are checked automatically, but download and installation only start after choosing **Update and restart**. Automatic checks can be disabled in Settings.

Existing releases require one manual download to gain the updater. Existing normal installations retain their application data. See README for portable-data migration instructions.

Npcap is installed separately on Windows. Compare downloads against `SHA256SUMS.txt`.
