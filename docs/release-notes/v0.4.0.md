Vale Companion adds personal storage browsing and category grouping, plus clearer prices and duplicate-stat filtering.

## Changes

- **Storage tab:** Browse the last observed personal storage contents beside Bag, with search, rule highlighting, an inspector, and a separate estimated total. Includes equipment, artifacts, cards, gems, materials, consumables, and cosmetics.
- **Category grouping:** Bag, Storage, and Rules preview share collapsible category headings with item counts and estimated totals. Choose Group: None to return to the flat grid. Search opens matching sections automatically.
- **Clearer prices:** Cards and gems show their per-item price on tiles. The inspector explicitly shows stack value and quantity calculations; bag totals still include the whole stack.
- **Multiple stat lines:** Each Market stat filter now has Lines: 1+, 2+, or 3+. Each distinct matching roll must meet the chosen minimum; values are not summed. Filters preserve line counts in their URLs.
- **Silent transfers:** Observed storage transfers update inventory without generating loot alerts.

## Storage and filtering notes

Open personal storage in-game to populate it. If it remains unavailable, transfer an item to trigger a complete update. Capture must be enabled. Storage shows its last observed timestamp and resets on a new game connection or app restart.

Storage pricing reuses the shared market cache without extra market requests. Materials, consumables, and cosmetics are displayed without estimates; category totals indicate when only some items are priced. The Market feed does not identify whether individual stat lines came from Chaos, so source-specific filtering is not included.

## Downloads and updating

Windows users should choose `ValeCompanion-0.4.0-windows-x64-setup.exe`. Installed v0.2.0 and later users can use Settings > Check for updates, then Update and restart. The portable Windows executable supports manual replacement; preserve your data folder.

Linux downloads include AppImage, DEB, and RPM. Windows requires Npcap; AppImage requires libpcap and non-root dumpcap configuration. DEB/RPM installers configure capture capabilities.

Windows binaries are unsigned. Matching source, updater metadata, blockmaps, and SHA256SUMS.txt accompany the release. Source ZIPs are not application installers.
