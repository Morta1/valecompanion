Vale Companion now offers Windows and Linux releases with user-controlled in-app updates.

## What's new

- **Windows installer:** A new per-user installer supports in-app updates. The portable executable remains available with manual replacement.
- **Linux packages:** AppImage, DEB, and RPM downloads, with fixes for desktop registration and compatibility with older dumpcap versions.
- **Update notifications:** See available versions and release notes, postpone an update, or skip a version.
- **You control installation:** Nothing downloads or installs until you choose **Update and restart**. Automatic checks can be disabled in Settings; closing the app normally never installs a pending update.
- **Session preservation:** The app saves your session and stops capture before installing. Failed final saves cancel installation.
- **Clearer errors:** Unavailable update feeds and connection problems show readable messages instead of technical stack traces.

## Which download?

| Platform | Download |
| --- | --- |
| Windows 10/11 x64 — recommended | `ValeCompanion-0.2.0-windows-x64-setup.exe` |
| Windows x64 — portable, manual updates | `ValeCompanion-0.2.0-windows-x64.exe` |
| Linux x64 — AppImage | `ValeCompanion-0.2.0-linux-x86_64.AppImage` |
| Debian/Ubuntu x64 | `ValeCompanion-0.2.0-linux-amd64.deb` |
| Fedora/RPM-based Linux x64 | `ValeCompanion-0.2.0-linux-x86_64.rpm` |

**Existing users:** Download this release manually once to enable future in-app updates. Windows users should choose the file ending in `-setup.exe`.

Normal application data stays in place. If you use `.valecompanion-portable` on Windows, keep your existing `data` folder when replacing the portable executable. Before switching to the installer, close the app, back up that folder, and follow the README's migration instructions.

Windows still requires separately installed Npcap. AppImage users need libpcap and non-root dumpcap configured; DEB/RPM installers configure the collector's capture capabilities. Native Linux updates may request system authorization.

Windows binaries are unsigned and may show an unknown-publisher warning. Download only from this repository and compare files against `SHA256SUMS.txt`.

Linux package testing covered Ubuntu 22.04 and Fedora 43 under a virtual display, including non-root capture startup, native package reinstall, and uninstall. AppImage used extract-and-run mode. Live game/Proton behavior and a real version-to-version in-app upgrade have not yet been validated.
