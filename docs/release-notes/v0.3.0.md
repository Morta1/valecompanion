Vale Companion adds bag market values, incremental market sync, and session tracking fixes.

## Changes

- See estimated bag and item values from ValeMarket, and open an item in Market with matching roll filters.
- Loot and Market share one snapshot cache. Subsequent syncs download reusable changes when smaller than a full snapshot, with automatic recovery for older revisions.
- Market publications run every ten minutes. Automatic client checks follow publication, and Refresh checks immediately while respecting retry backoff.
- Bag changes under the same item UID now reach the Market view, including refinement changes.
- Gold session time pauses when the game is not running; finished sessions preserve pause state and played intervals persist across restarts.
- Inventory keeps its dense layout, with refine levels in item names, simpler labels, and more readable inspector text.

## Downloads and updating

Windows users should choose `ValeCompanion-0.3.0-windows-x64-setup.exe`. The portable `.exe` is also available. Linux downloads include AppImage, DEB, and RPM.

Installed v0.2.0 users can use **Check for updates** in Settings, then **Update and restart**. Portable Windows users replace the executable manually while preserving their data folder. Older versions need a manual download. Normal application data stays in place.

Windows requires separately installed Npcap. Windows binaries are unsigned and may show an unknown-publisher warning. Linux AppImage users need libpcap and non-root dumpcap configured; DEB/RPM installers configure capture capabilities.

Matching source, updater metadata, blockmaps, and SHA256SUMS.txt accompany the downloads. Source ZIPs are not application installers.

## Validation

Client unit and integration tests, API tests, and local builds passed. Live production checks verified published revisions, incremental responses, unchanged responses, and local client persistence. The release workflow additionally validates Windows and Linux packages and runs installed-package smoke checks.

Representative multi-user Cloudflare CPU, cache-hit, and storage-cost measurements remain unmeasured; the incremental protocol avoids per-client database scans, but this release does not claim a measured production cost reduction.
